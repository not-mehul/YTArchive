Configuration.

What to trim, and at what fidelity.

SponsorBlock · segments to remove

Algorithm. Segments are looked up in the public SponsorBlock database, then trimmed from the muxed file by ffmpeg's chapter editor. Chapter timestamps shift to match.

Quality · format preset

1080p MP4 is the default — a balance of fidelity and disk. Audio presets skip video streams entirely.

Library · embed into file

Plex & Jellyfin. Writes title, uploader, thumbnail, and chapter markers into the file so libraries pick them up without sidecars.

Cookies · for age-restricted videos

Why. YouTube blocks age-restricted videos for signed-out clients. Pointing yt-dlp at a logged-in browser (--cookies-from-browser) is the simplest fix. The file path is used only when no browser is selected.

Concurrency & archive

Archive. Skips IDs already recorded in archive.txt at the destination root — safe to re-run against the same channel.
